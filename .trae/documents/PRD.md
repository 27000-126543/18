# 制造业生产设备预测性维护与备件智能管理系统 - Web版产品需求文档 (PRD)

## 1. 产品概述

### 1.1 项目背景
制造业工厂拥有数千台生产设备，传统维护方式（事后维修、定期保养）造成设备停机损失大、备件库存积压或短缺。本系统通过IoT传感器实时采集设备数据，AI预测设备故障，实现预测性维护和备件智能管理，通过Web界面为管理人员提供可视化决策支持。

### 1.2 产品定位
面向制造业工厂的设备管理部门，提供从数据采集、健康预测、工单调度、库存优化到报表分析的一体化Web管理平台。

### 1.3 目标用户
- **生产主管**：查看仪表盘、工单状态、设备健康度
- **维修工程师**：接收工单、执行维护、提交结果
- **库存管理员**：管理备件、处理采购需求
- **财务审批人**：审批超预算采购申请
- **工厂管理层**：查看日报月报、分析设备生命周期成本

## 3. 非功能需求

### 3.1 性能要求
- **数据采集**：支持5000台设备，每天50万条数据点采集，单轮采集≤30秒
- **页面加载**：仪表盘首屏加载≤2秒，图表渲染≤1秒
- **API响应**：95%接口响应时间≤500ms
- **并发用户**：支持50并发用户同时在线操作

### 3.2 高并发压力测试要求
- 模拟3000台设备连续1小时数据采集，数据库无锁死
- 验证TPS（每秒事务数）、平均响应时间、错误率指标
- 输出详细压力测试报告

### 3.3 可靠性
- 数据库WAL模式，支持高并发读写
- 邮件发送失败自动重试3次，记录失败日志
- 所有关键操作记录审计日志

### 3.4 兼容性
- 浏览器：Chrome 90+、Firefox 88+、Edge 90+、Safari 14+
- 分辨率：1366×768及以上（桌面优先）

## 4. 技术选型（概要）
- **后端框架**：Flask 3.0（轻量Python Web框架）
- **前端**：原生HTML5 + CSS3 + JavaScript，集成ECharts 5图表库
- **数据库**：SQLite3（WAL模式），后续可平滑迁移PostgreSQL
- **邮件**：smtplib标准库，支持SMTP SSL/TLS
- **导出**：openpyxl（Excel）、reportlab（PDF），缺失时自动pip安装
- **压测**：Python asyncio + aiohttp异步压测脚本

## 5. 界面风格定位

### 5.1 美学方向：工业科技风 (Industrial Tech)
- **色调**：深空蓝(#0A1628)为底，搭配电光青(#00D4FF)和告警橙(#FF6B35)，数据可视化采用青→橙渐变
- **字体**：标题使用JetBrains Mono等宽字体（科技感），正文使用Inter
- **视觉元素**：网格背景、发光边框、数据面板玻璃拟态、微扫描动画
- **布局**：侧边导航栏+顶部状态栏+主内容区三栏式，内容采用卡片网格化

### 5.2 差异化设计点
- 仪表盘KPI卡片采用霓虹发光效果，数值变化有数字滚动动画
- 设备健康评分使用仪表盘样式（Gauge Chart），颜色随分数从绿→黄→红渐变
- 实时数据图表有新数据点推入的涟漪动画
